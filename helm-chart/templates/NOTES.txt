========================================================================
  TODOLIST HELM CHART — QUICK START
========================================================================

1. Verify ingress controller
   kubectl get pods -n ingress-nginx

2. Install Todolist Helm chart
   helm install my-release oci://ghcr.io/omermigdal/todolist-k8s/todolist-k8s \
     --set secret.rootPassword=Password

3. Set custom host (optional)
   helm upgrade my-release --set ingress.host=todolist.local

4. Port-forward ingress controller
   kubectl port-forward -n ingress-nginx svc/ingress-nginx-controller 8080:80

5. Test the app at http://localhost:8080/
